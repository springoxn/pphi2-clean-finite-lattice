## §1 要证的确切陈述

1805 §3 的吸收链（`pphi2_bd_1805_route.md` §4）里，凡带 **W 侧**（相互作用场那一侧）的项，
在**按 `|Λ|` 归一化**的口径下都被写成**体积密度**形态；ROUND 29 §3 把它们统一成

```
   D_m(Λ) := (1/|Λ|) · m! Σ_{z,w∈Λ} K_1(z−w) C_Λ(z,w)^m      （格点写法）
           = (1/|Λ|) · m! ∫∫_{Λ×Λ} K_1(z−w) C_Λ(z,w)^m dz dw （连续统写法）
```

其中

- `K_1` = `(1−Δ)^{−1}` 的核（**Bessel 势**）：`K_1(u) = K₀(|u|)/(2π) > 0`，`∫K_1 = 1`（质量 1 的正概率核）；
- `C_Λ` = 区域 `Λ` 上的高斯场协方差（`(−Δ_Λ + m₀²)^{−1}`，Dirichlet；或自由场在 `Λ` 上的限制）；
- `m ≥ 1` 是 W 侧 Wick 幂的阶（吸收链里 `m ≤ n = deg P`）。

**要证**：`sup_{Λ} D_m(Λ) < ∞`，且上界**显式、与 Λ 无关**（ROUND 29 §3 的第 1、2 条只给了数值趋势）。

## §2 两条初等不等式

### 2.1 命题 A（Dirichlet 支配）

**命题 A.** 设 `Λ ⊂ ℝ²` 有界、`Δ_Λ` 为 Dirichlet Laplacian、`Δ` 为 `ℝ²` 上的 Laplacian。则对一切 `f ≥ 0`、`t > 0`
逐点 `e^{tΔ_Λ}f ≤ e^{tΔ}f`，从而对 a.e. `x,y`

```
   0 ≤ C_Λ(x,y) ≤ C_free(x,y) ,   C_free = (−Δ + m₀²)^{−1} .
```

*证.* 热核概率表示：`e^{tΔ_Λ}f(x) = E_x[f(B_t) ; τ_Λ > t] ≤ E_x[f(B_t)] = e^{tΔ}f(x)`，其中
`τ_Λ` 是 Brownian 路径离开 `Λ` 的时刻（**路杀**）。对 `t` 乘 `e^{−m₀²t}` 并积分（`m₀ > 0`）即得。∎

> **为什么这足够**：`C_Λ` 与 `C_free` 都是**非负核**（`K₀ > 0`），所以"支配"是**逐点**的，可以直接比较
> 被积函数而**不需要**任何谱/二次型的论证 —— 这一点是 ROUND 29 §3 用"Dirichlet 只删路径"定性描述的
> 那一句的**逐点化**。

### 2.2 命题 B（卷积–体积界）

**命题 B.** 对任意 `F: ℝ² → [0,∞]` 可测与任意有界可测 `Λ`：

```
   (1/|Λ|) ∫∫_{Λ×Λ} F(z−w) dz dw  =  ∫_{ℝ²} F(u) · (|Λ ∩ (Λ−u)| / |Λ|) du
                                  ≤  ∫_{ℝ²} F(u) du .
```

*证.* 换元 `u = z − w`，对 `z` 用 Fubini（被积函数非负，Tonelli 免可积性假设）：
`∫∫_{Λ×Λ}F(z−w)dzdw = ∫_{ℝ²}F(u)|Λ ∩ (Λ+u)|du`，而 `|Λ ∩ (Λ−u)| ≤ |Λ|`。∎

> **这就是"边界修正"的正确角色**：它**不是**一个需要估计渐近的误差项，而是重叠因子
> `|Λ∩(Λ−u)|/|Λ| ∈ [0,1]` —— 上界**恒成立**，不需要 `|∂Λ|/|Λ| → 0`。

### 2.3 定理（Λ-一致密度界）

**定理.** 对一切 `m ≥ 1` 与一切有界 `Λ`（其 `C_Λ` 被 `C_free` 支配）：

```
   D_m(Λ) ≤ J_m := m! ∫_{ℝ²} K_1(u) C_free(u)^m du = m! [(1−Δ)^{−1} C_free^m](0) < ∞ .
```

*证.* `K_1 ≥ 0`、`C_Λ^m ≥ 0`、`C_Λ ≤ C_free`（命题 A）⇒ `K_1 C_Λ^m ≤ K_1 C_free^m` 逐点，
故被积函数被一个 `Λ`-无关的**非负**函数支配；再用命题 B 把 `(1/|Λ|)∫∫_{Λ²}` 换成 `∫_{ℝ²}`。∎

## §3 `J_m` 的有限性与闭式

**有限性.** `J_m = m![(1−Δ)^{−1}C_free^m](0)`。近原点：`K_0(r) ≈ −log(r/2) − γ`，故径向被积函数
`r K_1(r)C_free(r)^m ≈ r·(log r)^{m+1}/(2π)^{m+1}`，被 2 维测度 `r dr` 吸收（对数幂可积）；
远场：`K_0(r) ≍ e^{−r}/√r`，故 `r K_1 C_free^m ≍ e^{−(m m₀+1)r}` 指数可积。⇒ `J_m < ∞` 对一切 `m`。

**闭式（`m = 1`）.** `J_1 = ∫K_1C_free = (1/2π)∫_0^∞ k/((1+k²)(m₀²+k²))dk`
（Fourier 表示或直接卷积 Bessel 核），分部化简得

```
   J_1(m₀) = log(m₀) / (2π (m₀² − 1)) ,        J_1(1) = 1/(4π) .
```

> 这正是 **(G-PU)** 的 `A_{1,κ}` 在 `κ = 1` 处的值（`1/(4πκ) = 1/(4π)`）。两个常数来自**不同**的推导：
> `A_{1,κ}` 来自 Fourier 积分 `(1/2π)∫k(1+k²)^{−(κ+1)}dk`（`UR1`），`J_1` 来自 Bessel 核的卷积
> `(1/2π)∫_0^∞ rK_0(r)K_0(m₀r)dr`。二者相符是该路线的一条**独立一致性核验**。

**数值锚点（探针 `IU3`/`IU4`）**：`J_1 = 0.0795774715…`（`= 1/(4π)`，相对误差 `5.1e−14`），
`J_2 = 0.0296859…`，`J_3 = 0.0254416…`，`J_4 = 0.0384451…`，`J_6 = 0.2948734…`；
`m₀ = 0.25/0.5/1/2/4` 上闭式与求积一致到 `≤ 2.9e−13`。

## §5 诚实边界

- **(H1)** §2 的两条命题**不是新数学**：命题 A 是 2 维 Brownian 路杀的教科书内容，命题 B 是 Fubini + `|Λ∩(Λ−u)| ≤ |Λ|`。
  本轮的新内容是 ①把它们**明确**组装成 ROUND 29 缺的那一步、②给出 `J_m` 的有限性与 `m = 1` 的闭式、
  ③把它与 (G-PU) 的 `κ = 1` 常数**对撞**。
- **(H2)** 本轮的定理覆盖的是**密度形态** `D_m(Λ)`（= ROUND 29 §3 的 GP-C8 量）。吸收链里**不是**
  这一形态的项（例如在不等式**左边**的矫顽/梯度项、以及由 `A_PPHI2_nelson_local`/`(V)` 提供的 W 侧矩）
  ROUND 29 §3 第 3 条已判"与区域无关"；本轮**未**重做那一条的逐项核对。
- **(H3)** `C_Λ` 取 Dirichlet（或自由场在 `Λ` 上的限制）；两者都被 `C_free` 支配，故定理对两种口径都成立。
  对 **UV 截断**版本（`C_{Λ,N} = K_N C_Λ K_N`）同一单调性给出 `C_{Λ,N} ≤ C_N`，故界对 `N` 一致（`IU1` 的
  离散形态即此）。
- **(H4)** 数值部分只用**比值、单调性、恒等式与收敛性**判读；绝对常数一律用**连续统**解析/求积值。
- **(H5)** 未跑 Lean；未动 `formal/`。
- **(H6)** **不夸大**：本轮**不**主张整条 IR 适配（乃至 `PPHI2_R2_COERCIVE_TIGHTNESS`）已闭合；
  主张的是 **ROUND 29 自己登记的 (H2) 这一条**被一条精确不等式解除。
