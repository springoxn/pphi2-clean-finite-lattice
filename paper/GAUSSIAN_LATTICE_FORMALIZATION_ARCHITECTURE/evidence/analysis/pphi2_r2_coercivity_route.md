## 2. 从指数紧性到本项目的紧性判据（初等，本文缝合）

BG 的结论是**加权限指数矩**，本项目的判据（`proofs/pphi2_r2_tightness.md` 定理 3.1、
上游 Lean `configuration_tight_of_uniform_second_moments`）要的是**一致二阶矩**。
两者的缝**初等**：

**引理 2.1（指数矩 ⟹ 一致二阶矩）.** 设 `sup_Λ ∫e^{δ‖φ‖²_{H^{−ε}(ρ)}}dθ_Λ ≤ C < ∞`。则
`sup_Λ E_{θ_Λ}‖φ‖²_{H^{−ε}(ρ)} ≤ (1/δ)log C < ∞`。
*证.* Jensen：`E[X] ≤ (1/δ)log E[e^{δX}]`（`X:=‖φ‖²_{H^{−ε}(ρ)}`，`log` 凹）。∎
**探针 C1a**：`Gamma(k,θ)` 族上精确核验（36 组，超出量恒 `0`）。

**引理 2.2（⟹ 测试函数上的一致二阶矩）.** `∀f∈S(ℝ²)`：
`sup_Λ E_{θ_Λ}[(ω(f))²] ≤ ‖f‖²_{H^{ε}(ρ^{−1/2})}·(1/δ)log C < ∞`。
*证.* 对偶配对 `|⟨φ,f⟩| ≤ ‖φ‖_{H^{−ε}(ρ^{1/2})}‖f‖_{H^{ε}(ρ^{−1/2})}`（Hölder/Cauchy–Schwarz），
右端 `f`-因子与 `Λ` 无关且有限（`f∈S`、`ρ^{−1/2}` 多项式）。∎
**探针 C5a/C5b**：配对**恒等式**残差 `2.1e−16`；`f` 侧范数有限。

**定理 2.3（ℝ² 紧性 ⟸ BG Lemma 24）.** Lemma 24 + 引理 2.1/2.2 + **Mitoma**（本项目定理 3.1，
