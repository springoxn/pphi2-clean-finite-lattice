# Fixed-volume weak-limit manuscript

This directory contains the source and built PDF for the theorem-specific paper on whole-sequence weak convergence of the fixed-physical-volume periodic lattice free-field laws on the weighted Fourier `H^{-3}` carrier.

The primary deliverable is `pphi2_fixed_volume_weak_limit.pdf`. The modular AMS-LaTeX source is included in `main.tex`, `sections/`, and `refs.bib`. The proof-spine figure is generated by `tools/generate_proof_spine.py`; its embedded PNG is `figures/weak_limit_spine.png`.

The formal proof entry point is `AImathPPhi2Clean.FixedVolumeWeakLimit`, exposed by the package build target `lake build AImathPPhi2Clean.FixedVolumeWeakLimit`. Its main theorem declaration is `periodicHMinusThree_fixedVolume_weak_limit_exists_with_expected_cylinders` in `AImathPPhi2Clean/PeriodicHMinusThreeWeakLimitMarginal.lean`.

The theorem concerns the concrete finite-source sequence. It does not assert an unconditional physical total-carrier lift. Author and affiliation metadata remain intentionally unfilled in the manuscript source.

To rebuild from this directory with Tectonic, create `build/` and run `tectonic --outdir build main.tex`. For an offline build, use `tectonic -C --outdir build main.tex` with the required TeX bundle already cached.
