# Provenance and reproducible release layers

This repository publishes successive stages of the AImath finite-lattice
Gaussian development. The current library extends and repairs earlier stages;
**the whole current tree is not byte-identical to the original archive**.
The Git history preserves the previous public two-dimensional release.

## Current two-, three- and four-dimensional release

The current `AImathPPhi2Clean/*.lean` files and library root were exported
byte-for-byte from the authoritative Lean proof workspace. The four-dimensional
entry theorem is
`Pphi2Clean.Continuum.fs4PeriodicFixedVolume_weak_tendsto_free`, in
`AImathPPhi2Clean/PeriodicFS4DProbeMoment.lean`. That module's SHA-256 is
`bd25228a14609af6eff7219473daac2310269fd9c6253bd7e3dfc3564ae68906`.

The export adds the four-dimensional Sobolev-weight, carrier, real-support,
compact-embedding and actual probe/measure-limit modules. Shared finite-Gaussian,
Fourier covariance and two-dimensional measure-limit modules also carry their
current proved repairs; they are not silently presented as unchanged archive
files. All previous library module paths remain present.

The three-dimensional fixed-volume theorem is
`Pphi2Clean.Continuum.periodic3DFixedVolume_weak_tendsto_gaussianTarget` in
`AImathPPhi2Clean/Periodic3DGaussianWeakLimit.lean`. The release adds the
dimension-specific raw atomic lift, carrier, tightness, finite-family marginal,
real-support and full weak-limit modules. Its actual source uses `a^3`; the 4D
Gaussian carrier is used only to construct the target by spectral restriction.
The proof guide is `docs/fs3/proof.md`. Its Lean footprint is confined to
`{propext, Classical.choice, Quot.sound}`.

`docs/fs4/release_evidence.json` is generated by executing a full library build,
the four-theorem query and the actual Lean version command in a separate release
staging checkout. It records:

- SHA-256 of every current library source, library root, Lake configuration,
  dependency manifest, toolchain and typed query;
- raw build/query output hashes and exact executed commands with exit codes;
- the exact four fully qualified theorem signatures and their axiom footprints;
- actual installed dependency Git revisions and clean checkout status, together
  with the raw Mathlib dependency manifest and its hash.

The package pins Lean `leanprover/lean4:v4.34.0-rc2` and upstream Mathlib commit
`852d20a84581aeba8527bd01d0be361d8c0e71c0`. The Lake declaration and lockfile agree
with the dependencies used for the current evidence. Earlier public instructions
named the Mathlib release tag while an old extension transcript recorded this
other commit; that mismatch is corrected for this release, not erased from
history. Transitive package revisions must also agree with Mathlib's manifest.

The offline checker verifies internal consistency and byte integrity. It does
not provide a trusted digital signature or replace a Lean rebuild. Use:

```bash
python verify.py --manifest --count --ext --fs4
python audit/check_fs4_release.py --self-test
python verify.py --all
```

Fresh Lean replay leaves frozen logs unchanged. The current checker creates an
isolated checkout under ignored `build/fs4-replay/`; legacy gates run on a
disposable copy because their historical scripts overwrite their log paths.
Raw replay outputs are separate from the published evidence.

`docs/fs4/proof.md` describes the intended model and the remaining representational
boundary. Exact raw complex mode identities and sharp paper constants are not
substituted for the formal all-N bound actually used by the final theorem.
The optional SymPy probe is a bounded check and is not theorem-level evidence.

## Five-dimensional actual-source H-minus-three endpoint

The independent 5D theorem project is published as a reproducible archive at
`paper/PERIODIC_GAUSSIAN_5D_HMINUS3/periodic_gaussian_5d_hminus3_endpoint.zip`.
Its SHA-256 is `3424b3573469c4f894efdfc911922a6348fb9e15f3302de0c56a047a460c06b`.
The archive includes the full Lean source tree, pinned Lake configuration and
lockfile, source-hash manifest, a typed endpoint contract, and the successful
build and axiom transcripts. The theorem is
`Pphi2Clean.Continuum.periodic5DFixedVolume_weak_tendsto_gaussianTarget`.

This project pins Lean `leanprover/lean4:v4.34.0-rc2` (commit
`6a10ac8c22beadecabdbb0919c2b50214762f91d`) and Mathlib commit
`852d20a84581aeba8527bd01d0be361d8c0e71c0`. The queried endpoint footprint is
exactly `{propext, Classical.choice, Quot.sound}`; the 5D source has no `sorry`
or declared `axiom`. The published transcript is also available at
`audit/periodic5d_hminus3_endpoint.log`.

The five-dimensional source is the physical `a^5` raw atomic lift, not a higher-
dimensional auxiliary slice. Its uniform H^-3 tail, compact containment, all
finite real Fourier-family resolvent Gaussian marginals, uniqueness and full
sequence weak convergence are documented in
`paper/PERIODIC_GAUSSIAN_5D_HMINUS3/inputs/periodic5d_hminus3_endpoint.md`.
The endpoint proves all finite Fourier-family Gaussian laws, not a separate
infinite-dimensional `IsGaussian` predicate.

## Byte stability and licensing

`.gitattributes` declares `* -text`, so Git does not rewrite line endings.
`MANIFEST.sha256` enumerates every published file except itself and generated
build/dependency directories. The manifest is also checked on a fresh clone
after publication. It establishes byte consistency, not mathematical truth.

The license remains Apache-2.0. The full license text and `NOTICE` are retained.
No third-party literature PDFs, credentials, runtime databases or compiled
Mathlib caches are included.
